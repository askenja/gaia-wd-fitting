
## White dwarf population modelling with CALOMERA

This repository contains the Jupyter notebooks used for colour–magnitude diagram fitting of the local stellar populations, including white dwarfs from Gaia DR3. For modelling, the CALOMERA release of the Just-Jahreiß (JJ) model of the Milky Way disk has been used (see the official [jjmodel repository](https://github.com/askenja/jjmodel)).
